# ForgeYantra — Internship Landing Page

A modern, responsive, and student-focused internship landing page developed for **ForgeYantra** as a technical internship assignment.

## 🌐 Live Demo

**Live Website:** `YOUR_VERCEL_URL_HERE`

## ✨ Features

* Responsive design for desktop, tablet, and mobile
* Modern dark/light theme
* Internship role filtering
* Interactive navigation and smooth scrolling
* Mobile hamburger menu
* Internship application form with validation
* Scroll animations
* Back-to-top button
* Accessible and semantic HTML
* Frontend-only implementation

## 🛠️ Tech Stack

* HTML5
* CSS3
* Vanilla JavaScript (ES6+)
* LocalStorage
* Intersection Observer API

## ▶️ Run Locally

### Direct Browser

Open `index.html` in any modern browser.

### VS Code

Open the project in VS Code → Right-click `index.html` → **Open with Live Server**.

### Python Server

```bash
python -m http.server 3000
```

Then open:

`http://localhost:3000`

## 📝 Note

This is a **frontend-only project**. The application form performs client-side validation and does not send or store data on a backend.
